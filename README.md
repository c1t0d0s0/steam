# 🚀 STEAM探検隊 〜めざせ！ひらめきマスター〜
### (STEAM Lab Adventure)

小学生および中学受験生（理科・算数・思考力問題）を対象とした、**体験型STEAM教育ウェブアプリケーション**です。  
科学（Science）・技術（Technology）・工学（Engineering）・芸術（Art）・数学（Math）の各領域をテーマにした5つの島と6つのインタラクティブなゲームモジュールを通じて、公式の丸暗記ではなく「原理の直感的理解」と「ひらめき」を楽しく身につけることができます。

---

## 🌟 主な特徴

- **全108問の豊富な学習コンテンツ**
  - 6つのゲームモジュール × 各6ステージ（初級〜達人）× 各ステージ3バリエーション（全108問）
  - 中学入試頻出のテーマを基礎から難関校レベルの発展問題まで網羅
- **全問に「中学受験のツボ」＆「詳しいステップ解説」付き**
  - 解いた後に「なぜその答えになるのか」「入試ではどう着目すべきか」を視覚的・論理的に解説
- **ゲーム感覚で続くゲーミフィケーション設計**
  - **レベル＆称号システム**: 経験値（XP）を獲得して「見習い研究員」から「STEAMグランドマスター」へ昇格
  - **歴史的遺物・科学アイテムガチャ＆博物館**: アルキメデスの王冠、ガリレオの望遠鏡、パスカリーヌなど、全15種以上の科学遺物コレクション（入試トリビア解説付き）
  - **アチーブメントバッジ**: 「はじめてのひらめき」から「グランドエクスプローラー」まで多彩な実績
  - **スタンプ帳・星報酬**: ステージクリアやログインで星を獲得
- **外部リソース不要のインタラクティブ体験**
  - Web Audio API によるシンセサイザー効果音生成（通信遅延や外部音声ファイル不要）
  - HTML5 Canvas を用いた紙吹雪（Confetti）エフェクト
  - タッチ・PC両対応の完全レスポンシブデザイン

## 🗺️ 収録ゲーム＆カリキュラム対応

### 1. 🔬 サイエンス島（Science: 理科）
* **ゲーム**: **てこ天秤の釣り合いパズル**
* **学習テーマ**: てこの規則性、力のモーメント（支点からの距離 × おもりの重さ）、左右複数箇所へのおもりの吊り下げ、逆算問題
* **中学受験のポイント**: 左右の回転力（トルク）の釣り合いの式を立てる力を養います。

### 2. 📐 マス・アイランド（Math: 算数 - 空間把握）
* **ゲーム**: **立体ブロック積み木数え**
* **学習テーマ**: 3D立体把握、見えない隠れブロック（死角）の推測、上から見た図（投影図）に各列の高さを書き込む解法テクニック
* **中学受験のポイント**: 入試頻出の「見取り図と投影図」の対応関係を3Dモデルと上面図で体得します。

### 3. 🐢 マス・アイランド（Math: 算数 - 特殊算）
* **ゲーム**: **つるかめ算ビジュアルアリーナ**
* **学習テーマ**: 和差算・つるかめ算、仮定法（全員ツルだったら／全員カメだったら）、足の差による置換
* **中学受験のポイント**: 面積図のイメージと直結するビジュアルシミュレーションで、立式が苦手な子供でも直感的に理解できます。

### 4. ⚙️ エンジニア鉱山（Engineering: 工学）
* **ゲーム**: **歯車（ギア）伝達パズル**
* **学習テーマ**: 歯車の噛み合わせと回転方向（隣同士は逆回転）、奇数個・偶数個の伝達則、歯数と回転数の反比例関係、多段ギアトレイン
* **中学受験のポイント**: 理科の「力学・滑車と輪軸・からくり」に通じる比例・反比例の直感を養います。

### 5. 🎨 デザイン神殿（Art: 幾何・空間芸術）
* **ゲーム**: **立方体の展開図マスター**
* **学習テーマ**: 立方体の基本展開図11種類（1-4-1型、2-3-1型、2-2-2型、3-3型）、対面・隣接面の関係、サイコロの目の和（向かい合う面の和が7）
* **中学受験のポイント**: 頭の中で組み立てるのが難しい展開図を、グリッド視覚化と回転対称性の法則から攻略します。

### 6. 🤖 テックラボ（Technology: 情報・論理）
* **ゲーム**: **アルゴ・迷路（プログラミング的思考）**
* **学習テーマ**: 順次処理、向きの概念（ロボット視点での左折・右折）、最短経路問題、障害物回避アルゴリズム
* **中学受験のポイント**: 小学校プログラミング教育および情報・適性検査型の思考力入試に対応。

## 🚀 クイックスタート

### 必要要件
- Node.js 18.0.0 以上
- npm 9.0.0 以上

### インストールと起動

1. **リポジトリのクローン・依存関係のインストール**:
   ```bash
   git clone <repository-url>
   cd steam
   npm install
   ```

2. **開発サーバーの起動**:
   ```bash
   npm run dev
   ```
   ブラウザで `http://localhost:5173` を開いてプレイできます。

3. **テストの実行**:
   ```bash
   npm test
   ```
   ゲームロジック・算数計算エンジン・UI統合テスト（全17テスト）を実行します。

4. **プロダクションビルド**:
   ```bash
   npm run build
   ```
   型チェック（`tsc -b`）および最適化された本番用バンドルを `dist/` に出力します。

5. **本番プレビュー**:
   ```bash
   npm run preview
   ```
